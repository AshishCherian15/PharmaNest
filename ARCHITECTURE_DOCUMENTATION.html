📋 Project Overview

PharmaNest is a comprehensive pharmacy management system designed for modern healthcare providers. It combines a powerful admin dashboard for inventory, orders, and prescriptions with a customer-facing storefront for medicine purchases.

Key Capabilities

👥 Multi-Role System

  • Admin - Full system control
  • Pharmacist - Medication verification
  • Staff - Operations support
  • Customer - Online purchases

📦 Inventory Management

  • Medicine catalog with categories
  • Real-time stock tracking
  • Expiry date alerts
  • Low stock warnings

🛒 Customer Portal

  • Medicine browsing & search
  • Shopping cart management
  • Prescription-linked checkout
  • Order history tracking

📊 Analytics & Reports

  • Revenue tracking
  • Sales trends
  • Top medicines
  • Inventory valuation

Key Frontend Features

1. Responsive Dashboard

Mobile-first design with breakpoints for all screen sizes. The dashboard adapts seamlessly from mobile phones to 4K displays.

2. Authentication Flow

Splash Screen → Login/Register → Protected Routes

  • Session-based with JWT tokens
  • Role-based access control (RBAC)
  • Automatic redirect based on role
  • HTTP-only cookie storage

3. Data Tables

Generic, reusable data table component with sorting, filtering, pagination, and bulk actions.

4. Analytics Dashboard

Professional reporting with KPI cards, period filters, trend charts, and CSV export functionality.

5. Stitch Design System

Consistent visual language using Stitch design tokens with Tailwind CSS custom properties.

⚙️ Backend Architecture

The backend is built with Next.js API Routes, providing a lightweight yet powerful REST API for the frontend and third-party integrations.

API Architecture

Base Response Format

// Success Response
{
  "success": true,
  "data": { /* payload */ },
  "status": 200
}

// Error Response
{
  "success": false,
  "error": "Error message",
  "status": 400,
  "details": { /* optional */ }
}

Core Systems

1. Authentication System

  • Token Type: HMAC-SHA256 signed JWT
  • Storage: HTTP-only cookies (secure, non-XSS vulnerable)
  • Expiry: 7 days default
  • Password Policy: Min 8 chars, uppercase, lowercase, number

2. Stock Management

  • Real-time Stock: Snapshot endpoint for inventory checking
  • Optimistic Locking: Version-based conflict detection during checkout
  • Stock Reservation: Items reserved during order creation
  • Auto Refresh: 30-second polling in cart

3. Prescription Validation

  • Rx Medicines: Require prescription for purchase
  • Eligibility Check: Verify customer has valid prescription
  • Status Tracking: pending → verified → rejected
  • Doctor Records: Store doctor name and details

4. Order Processing

  • Order Stages: Placed → Processing → Shipped → Delivered → Cancelled
  • Stock Reservation: Decrement on order creation
  • Admin Fulfillment: Status updates by staff
  • Stock Release: On admin cancel if eligible

🔌 API Endpoints

Authentication Endpoints

POST /api/auth/login - User authentication
POST /api/auth/register - Customer registration (customer-only)
POST /api/auth/logout - Session termination
GET /api/auth/me - Current user profile

Catalog Endpoints

GET /api/catalog/stock - Real-time stock snapshot

Customer Order Endpoints

POST /api/customer/orders - Create new order
GET /api/customer/orders - Get customer orders
GET /api/customer/prescriptions/eligibility - Check prescription validity

Admin Endpoints

GET /api/admin/customer-orders - All customer orders (pagination)
PATCH /api/admin/customer-orders/{orderId} - Update order status
GET /api/admin/inventory/alerts - Stock and expiry alerts
GET /api/admin/reports/sales - Sales analytics

🔒 Security

⚠️ Security First: All inputs are validated server-side, sensitive data is stored in environment variables, and session management uses secure HTTP-only cookies.

Security Features

Feature Implementation
Token Signing HMAC-SHA256 with AUTH_SECRET (min 32 chars)
Session Storage HTTP-only cookies (prevents XSS attacks)
Password Hashing PBKDF2 with 100K iterations (future: bcrypt)
Input Validation Server-side validation for all endpoints
CORS Configured for specified origins only
Security Headers XSS, CSRF, Clickjacking protections
Rate Limiting 5/15min login, 100/min general endpoints
Role-Based Access Admin/Staff/Customer permissions enforced

Environment Variables

# Required
AUTH_SECRET=your-secret-key-min-32-chars
AUTH_DEFAULT_PASSWORD=TemporaryPass123

# Optional
NODE_ENV=production
LOG_LEVEL=info
CORS_ORIGIN=https://pharmanest.com

🔧 Setup Instructions

Prerequisites

  • Node.js 18+ or higher
  • npm 9+ or yarn
  • Git

Development Setup

# Clone the repository
git clone https://github.com/AshishCherian15/PharmaNest.git
cd PharmaNest

# Install dependencies
npm install

# Create .env.local
echo 'AUTH_SECRET=your-secret-key-here' > .env.local
echo 'AUTH_DEFAULT_PASSWORD=TempPass123' >> .env.local

# Run development server
npm run dev

# Server runs on http://localhost:3000
