# **App Name**: Pharma Nest

## Core Features:

- Secure User Access: Role-based authentication for admins, pharmacists, and staff; username/password login; password reset via email or security question.
- System Overview Dashboard: Provides a quick overview of system status with total medicines, suppliers, recent sales; displays alerts for low stock and expiring medicines; includes daily/weekly sales graphs; and offers navigation shortcuts.
- Comprehensive Inventory Management: CRUD operations for product details (name, description, category, price, quantity, expiry date, image); search/filter by category, expiry, or supplier; and export inventory lists to Excel/PDF.
- Supplier Database Management: Maintain supplier profiles with name, contact, address, and products supplied; edit/update supplier info; search by product or name; link suppliers to inventory items; and generate purchase orders for low stock.
- Point-of-Sale System: POS-style interface for quick billing; selection of products and quantity, auto-calculation of total; application of discounts or taxes; saving transactions with timestamps; generation of print/email receipts; and viewing sales history with filters.
- Proactive Alert System: Notifies staff about critical issues like low stock levels and expiring medicines; integrates a notification panel on the dashboard; and allows marking alerts as resolved.
- Reporting & Analytics Suite: Generates inventory reports (stock levels, expiry dates), sales reports (revenue, top-selling products), and supplier reports (deliveries, linked products); exports reports in PDF/Excel; and visualizes data with charts/graphs.
- User & Role Management (Admin): Allows admins to add new users with roles, edit user details, deactivate/remove users, and view activity logs for item changes.
- Application Settings: Provides options to update user profile info (name, email, password), change language (English + local), switch theme (light/dark), and configure tax/discount rules.

## Style Guidelines:

- Primary color: Medium Blue (#1F73B8) for professionalism and key interactive elements.
- Background color: Light Bluish-Gray (#EAF0F3) for a clean and readable interface.
- Accent colors: Various shades of blue for highlighting and interactive elements.
- Feedback colors: Green (#4CAF50) for success and Red (#E53935) for alerts/errors.
- Primary font: 'Inter' (sans-serif) for a modern, clean, and highly readable aesthetic.
- Headings: Bold and proportionally larger than body text to establish clear visual hierarchy.
- Body text: Neutral tone and optimized for high readability across various screen sizes.
- Use simple line icons for core functionalities like inventory, suppliers, sales, and alerts.
- Maintain consistent stroke width across all icons for visual harmony.
- Sidebar navigation for clear categorization and module access.
- Card-based UI for displaying information in the dashboard and inventory sections.
- Responsive design adaptable to various screen sizes.
- Efficient form designs for data entry.
- Subtle transitions for smooth navigation between pages or sections.
- Smooth animations for form validation feedback to guide users.
- Alert notifications with gentle fade-in and fade-out animations.
